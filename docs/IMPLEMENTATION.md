## Product and operating decisions

- One research application: Overview, Conflicts, Protests, U.S. Elections, Data & Methodology, plus a protected editorial workspace.
- Preserve all 82 conflict actors and 75 relationships and stable legacy IDs, labeled inherited/unverified until evidence is recovered. News discovery is not an event or verified relationship update.

- Elections focus on 2026 House/Senate results, certification, recounts, litigation, documented institutional actions, and transition. No forecast, fabricated winner, or unlabeled live count. Source reporting status is distinct from editorial review status. District vintage and unavailable boundaries are explicit.
- Temperature uses transparent observed counts and comparison eligibility. No invented composite score, ranking, ideological inference, or timing-derived causal links.

## Concrete architecture

- React + TypeScript + Vite for a modular responsive public/editorial application, hash routes compatible with existing Pages URLs, locally bundled map geometry and dependencies.
- Python FastAPI + SQLAlchemy modular service; versioned relational schema, explicit domain models, evidence links, revisions, coverage and jobs. PostgreSQL for service deployments; SQLite supports the immediately runnable single-maintainer local workspace and offline build/restore verification.
- A versioned public snapshot is generated by the same domain/data service consumed by the live API. GitHub Pages publishes only the deliberate frontend build. Public snapshot hosting remains usable without exposing the editor or database.
- Review and correction run against the actual local API and persistent SQL store. A containerized PostgreSQL/service deployment path will be provided and tested where host runtime permits. No new paid service or subscription is assumed.
- Scheduled discovery preserves candidates, idempotency and run health; it cannot auto-promote article counts into real-world occurrences or overwrite reviewed claims.
- Original dirty checkout in `/Users/youyou/Downloads/WorldWar` is untouched. Work proceeds from GitHub main `1001095` in isolated worktrees. The coordinator owns shared contracts, integration, root manifests and release wiring.
